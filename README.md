## How I Work

**문제를 재현하고 근거를 바탕으로 원인을 찾습니다.**  
오류가 발생한 실행 조건을 구성하고, 로그와 디버깅 결과를 비교하며 원인을 좁혀갑니다.

**실패 상황에서도 예측 가능한 동작을 고민합니다.**  
이벤트 중복, 상태 경쟁, 트랜잭션 경계와 외부 서비스 장애를 고려해 기능을 설계합니다.

**새로운 기술을 직접 검증하며 학습합니다.**  
문서나 AI의 설명을 그대로 받아들이지 않고 코드, 실행 결과, 테스트를 통해 확인합니다.

**팀이 함께 이해하고 유지할 수 있는 결과를 만듭니다.**  
기술적 장점뿐 아니라 팀의 경험과 목표를 고려하고, 검증 과정과 결과를 기록합니다.
