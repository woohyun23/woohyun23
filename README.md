## How I Work

**문제를 먼저 재현합니다.**  
오류가 발생한 조건과 정상 동작 조건을 비교하고, 로그·코드·DB 상태를 확인해 원인을 좁혀갑니다.

**실패 상황을 포함해 설계합니다.**  
정상 흐름뿐 아니라 중복 요청, 동시 실행, 외부 서비스 장애와 부분 실패를 함께 고려합니다.

**구현 결과의 범위를 구분합니다.**  
측정 환경과 조건을 기록하고, 확인한 결과와 아직 보장하지 못한 영역을 구분합니다.

**팀이 이어서 작업할 수 있는 근거를 남깁니다.**  
테스트 결과와 판단 근거, 실행 및 확장 절차를 문서화합니다.
